# KitRace

**KitRace** is a 3D bike-racing adventure built around fast rides, expressive stunts, and distinct environments. Choose a route, ride through the terrain, dodge obstacles, chain tricks, collect shards, and chase your best finish.

## Ride routes

- **Neon Sprint** — winding forest trails
- **Coastline Rush** — ocean-side roads and coastal bends
- **Dust Devil** — sandy desert terrain
- **Mountain Pass** — rocky highland roads
- **City Lights** — an illuminated urban route

## Features

- Browser-based 3D riding powered by Three.js
- Five visually distinct routes
- Stunts, jumps, boosts, bells, and braking
- Collectibles, score, combo, and ride-time HUD
- Solo rides and room-based play options
- Optional AI opponents
- Short Web3 learning moments woven into the experience

## Run locally

Requirements: Node.js and npm.

```sh
npm install
npm run dev
```

Create a production build with:

```sh
npm run build
npm run preview
```

## Tech stack

- Vite
- Three.js
- Firebase integration for shared game data where configured
